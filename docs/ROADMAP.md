# Personal Reading OS 路线图

## 阶段原则

每次只开发一个阶段。阶段开始前阅读 [PRD.md](./PRD.md)、[DESIGN.md](./DESIGN.md)、[DATABASE.md](./DATABASE.md) 和本文件；阶段完成后检查相应页面的桌面/平板/手机表现，运行必要检查并记录遗留问题。阶段中的依赖与具体实现方案应在该阶段说明和确认。

| 阶段 | 目标与交付 | 完成判据 |
| --- | --- | --- |
| **V0.1 基础 UI** | 建立响应式 App Shell、导航、页面骨架、基础排版与空状态；九个计划路由可到达。 | 桌面、平板、手机布局可用；导航状态清楚；不暗示数据功能已上线。 |
| **V0.2 用户系统** | 选择并接入 Supabase 认证，建立账户会话与私有数据边界；初步设置页面。 | 登录/退出及受保护页面流程可用；凭据不在源码；RLS 策略可验证。 |
| **V0.3 书架** | 实现 EPUB/PDF 导入、私有文件存储、书籍元数据、封面、状态与基础筛选。 | 导入后可在书架查看/管理书籍；失败与重复导入有反馈；跨账户不能读取文件。 |
| **V0.4 EPUB 阅读器** | 实现 EPUB 正文、目录、排版设置与基础导航。 | 可打开书架中的 EPUB，并在桌面和触屏设备上稳定翻阅。 |
| **V0.5 PDF 阅读器** | 实现 PDF 页面阅读、页码导航、缩放与适配布局。 | 可打开书架中的 PDF，页面和导航在目标设备上可用。 |
| **V0.6 阅读进度** | 保存/恢复两种格式的位置，记录可靠的阅读会话与进度。 | 重新打开能恢复位置；跨设备同步规则明确并可验证；统计有可信基础数据。 |
| **V0.7 笔记与高亮** | 实现 EPUB/PDF 摘录、高亮、阅读笔记和跳回原文。 | 笔记保留来源与可用位置；从笔记可返回原文；定位失败有说明。 |
| **V0.8 灵感/心得/随笔** | 实现三类 Entry、关联与引用、跨主要页面快速记录。 | 各类型可创建/编辑/查看；心得可关联书籍与笔记；随笔可引用已有内容。 |
| **V0.9 搜索/标签/统计** | 实现跨内容搜索、统一标签管理、Dashboard 摘要和阅读统计视图。 | 书籍、笔记/摘录及三类 Entry 可检索；标签筛选一致；统计有可追溯来源。 |
| **V1.0 PWA + 正式部署** | 完成安装体验、生产部署、质量与隐私检查、主要流程打磨。 | 目标设备完成主要流程；PWA 可添加到主屏幕；生产环境可用。离线能力范围需单独确定。 |
| **V2.0 AI** | 规划并逐项评估 AI 问书、个人笔记问答、笔记整理、跨书观点联系、写作助手、双向链接、知识图谱、语义搜索和年度 AI 阅读总结。 | 当前仅保留规划；在 V1.0 完成后再决定范围、数据授权、成本与优先级。 |

## 当前状态

当前仅完成项目规划和文档初始化。下一阶段是 **V0.1 基础 UI**；本次不编写 V0.1 页面或业务代码，也不安装依赖。
