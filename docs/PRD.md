# Personal Reading OS 产品需求文档

## 1. 产品定位

Personal Reading OS 是主要供个人长期使用的跨平台阅读与知识管理 Web 应用。它连接“阅读 → 摘录 → 笔记 → 思考 → 灵感 → 写作 → 知识连接”，让阅读内容能够持续转化为自己的知识和作品。

首要使用者是同一位读者在 Mac、Windows、iPad、iPhone 和 Android 之间切换。V1.0 以响应式 Web 应用为交付形式，最终支持作为 PWA 添加到主屏幕。产品强调个人内容的所有权、可回溯的来源、安静的阅读体验和长期可维护性。

## 2. 核心用户场景

1. 导入 EPUB 或 PDF，整理封面、作者、分类、标签与阅读状态，在书架上决定下一本读什么。
2. 在不同设备上继续阅读，恢复上次位置；调节适用的阅读设置，在原文上高亮、摘录并写笔记。
3. 从笔记回到原文位置，查看当时的上下文；按书籍、章节或标签整理零散记录。
4. 在任意主要页面快速记录想法，稍后扩展为章节心得、整本书心得或随笔。
5. 写作时引用自己的书籍、笔记与灵感，通过全局搜索找回材料。
6. 用阅读摘要与统计回顾习惯，而不让统计压过阅读本身。

## 3. V1.0 功能范围

### 3.1 Dashboard `/`

- 展示当前阅读与最近阅读，提供继续阅读入口。
- 展示最近笔记、最近灵感与阅读统计摘要。
- 提供快速记录入口。
- 内容缺失时提供明确空状态和下一步操作。

### 3.2 我的书架 `/library`

- 导入和管理 EPUB、PDF；TXT 作为后续可选格式，不列入 V1.0 验收。
- 展示封面、书名、作者、分类、标签、阅读状态、阅读进度。
- 阅读状态为“想读 / 在读 / 已读 / 暂停”。支持修改、筛选和查找书籍。
- 导入失败、重复书籍和不支持的文件格式需要清晰反馈；具体文件大小限制在实现阶段确定。

### 3.3 阅读器 `/reader/[bookId]`

- 支持 EPUB 与 PDF 阅读、目录或页码导航、进度显示和自动保存阅读位置。
- EPUB 支持字号、行距、阅读主题等适用的排版设置；PDF 支持其格式适用的缩放和页面导航。深色模式应兼顾原文可读性。
- 支持划线、高亮、摘录、添加笔记，以及从笔记返回原文位置。
- 原文定位需在可用时准确恢复；无法定位时仍可展示摘录并提示原因。

### 3.4 阅读笔记 `/notes`

- 笔记记录来源书籍、章节、原文摘录、用户笔记、标签、创建时间和原文位置。
- 支持创建、编辑、删除、按来源或标签查看，以及跳回原文。
- 快速创建时允许暂未关联书籍；没有原文位置的笔记不显示无效的“返回原文”操作。

### 3.5 阅读心得 `/reflections`

- 支持针对整本书或章节撰写长文本心得，并关联书籍和相关笔记。
- 能够独立浏览、编辑和按书籍查找。

### 3.6 灵感库 `/ideas`

- 快速记录写作灵感、观点、问题、待研究内容、金句与思考。
- 支持编辑、标签与后续查找；不强制关联书籍。

### 3.7 随笔 `/writing`

- 支持长文本写作，引用自己的书籍、笔记与灵感。
- V1.0 使用可维护的基础文本编辑方案；Markdown 或富文本能力在实现阶段按需求选择，不作为当前文档初始化任务的一部分。
- 自动保存属于后续需求，不列入 V1.0 验收。

### 3.8 标签与搜索

- 标签统一用于书籍、笔记、灵感、心得和随笔；支持创建、重命名、删除及内容筛选。
- `/search` 提供跨书籍、阅读笔记、摘录、灵感、心得和随笔的全局搜索。
- 搜索结果应标明类型与来源，并可进入对应内容。语义搜索属于 V2.0。

### 3.9 快速记录与统计

- 在主要页面可快速创建笔记、灵感、心得或随笔，保持当前阅读或浏览上下文。
- 阅读统计规划今日、本周、本月阅读时间，阅读天数、连续阅读天数、已读书籍数量、笔记数量、阅读日历和年度阅读报告。
- V1.0 统计以可可靠采集的阅读会话和内容数据为基础；后台停留、重复计时和跨设备同步规则在 V0.6/V0.9 明确。年度报告可基于已有数据逐步完善。

### 3.10 设置 `/settings`

- 管理阅读偏好、外观与后续账户相关设置；标签管理可在设置中提供统一入口。
- 需要说明哪些设置随账户同步，哪些仅保存在当前设备；在相关阶段确定具体策略。

## 4. 功能质量要求

- **跨设备**：桌面、平板、手机均可完成主要阅读与记录操作；触控目标、键盘焦点和文本可读性需要验证。
- **持久化**：完成相应阶段后，书籍、阅读位置、笔记和条目应可靠保存；关键写入失败时给出反馈。
- **隐私**：个人书籍与内容默认仅本人可访问；接入 Supabase 时启用私有存储与行级访问控制。
- **性能**：优先保证长文本阅读、书架浏览和搜索响应；在真实数据规模出现后确定量化指标。
- **可访问性**：使用语义结构、清晰对比度、键盘操作和状态提示。
- **可回溯**：摘录与笔记尽可能保留来源和可用的原文位置；格式差异需显式处理。

## 5. 阶段边界

V1.0 的功能按 [ROADMAP.md](./ROADMAP.md) 从 V0.1 逐阶段实现。当前任务只初始化规划文档与开发规则，不开发 UI、数据连接或业务逻辑。V0.1 只建立响应式基础 UI 与页面结构；后续阶段的功能应在各自阶段实现。

V2.0 仅规划：AI 问书、基于个人笔记的问答、AI 自动整理笔记、发现跨书观点联系、AI 写作助手、双向链接、知识图谱、语义搜索、年度 AI 阅读总结。V2.0 不属于 V1.0 的开发和验收范围。

## 6. 待后续阶段确定的产品决策

- 账户与私有书籍文件的存储配额、导入大小限制和备份方式。
- PDF 高亮定位的精度与跨版本稳定性；EPUB 位置在重排或文件替换后的恢复策略。
- 阅读会话如何计时、跨设备合并，以及年度报告的呈现深度。
- 写作编辑格式和内容导出格式。
